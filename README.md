# Slow Cup — TypeScript coffee website

Responsive coffee menu with category filters, a quantity-controlled cart,
subtotal calculation, and browser-local cart persistence.

## View immediately
Open index.html in your browser. Compiled JavaScript is already included.
Alternatively run python3 -m http.server 8000 inside this folder and visit
http://localhost:8000.

## Develop with TypeScript
Install Node.js, then run:

    npm install
    npm run build

Edit src/app.ts and rebuild to update assets/app.js.
Edit style.css for colors and layout; index.html for page text.

All illustrations use CSS and work offline.
Prices are illustrative USD amounts. This is a demo: no payment processing,
order submission, or delivery service is connected.
